# 🚀 ZULÜMSÜZ VC Token Bot

Discord sesli kanal AFK sistemi botu.

## 📦 Railway'e Deploy

1. Bu repository'yi fork edin veya kopyalayın
2. Railway.app'e gidin
3. "Deploy from GitHub repo" seçin
4. Bu repository'yi seçin
5. Environment Variables ekleyin:
   - `BOT_TOKEN` = Discord bot tokeniniz

## ⚙️ Gereksinimler

- Python 3.11+
- discord.py
- aiohttp

## 🔧 Kurulum

```bash
pip install -r requirements.txt
python vc_token_bot.py
```

## 📝 Notlar

- Bot TOKEN'ını `.env` dosyasına veya environment variable olarak ekleyin
- Railway ücretsiz planı sınırlıdır
